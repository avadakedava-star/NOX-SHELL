# final-test 同步更新

本次在独立分支同步当前 final-test 的功能源码，保留公开仓库的 NOX-SHELL 模块命名、环境变量配置和旧部署兼容支持。未变更 main，也未创建正式版本标签。

## 前端与终端

- 更新 NOX-SHELL 界面、图标、面板布局、聊天输入区及任务状态展示。
- 修复新输入组件漏传 terminalSessionId：界面明确传递终端编号，统一发送入口在调用方省略时从当前已连接终端取得编号。
- 显式指定目标仍有优先权；null 表示不关联终端的纯聊天。等待创建聊天会话期间切换服务器，不改变已发起请求的目标。
- 增强模式每轮同步 ADK Session；根请求纠正重连前的旧终端编号，子任务保留显式上下文。

## 执行策略

- 观察窗口替代固定的三分钟聊天截断和默认两分钟子任务截断。长命令使用已有的后台任务机制。
- 从真实叶子工具结果记录新信息；重复参数变化、时间戳、心跳、派发总结与模型自述不能单独当成进展。
- reportProgress 要求真实证据编号、验收条件、判断与下一项验证；根任务和子任务的条件分开保存。模型解释仍是待验证判断，不会自动证明任务完成。
- 后台作业采集输出变化与进程组 CPU/磁盘活动。没有进展先核查，持续无进展暂停；恢复先查询原作业，不重复执行修改。
- 保留单次查询的等待时限、明确指定的命令终止时限、最终资源上限、危险操作与未知副作用保护。
- 新增核查中、连接中断、暂停待核查状态；暂停不会误标成已完成或业务失败。

## 配置与兼容

- 模型接口地址、模型名称通过环境变量配置，不包含本机代理服务凭据。
- 保留新旧加密密钥变量、旧用户标识、旧 Prompt 信封和旧远端作业目录的读取支持。
- Windows 启动脚本从 JAVA_HOME 或 PATH 寻找 Java，前端使用现有任务计划托管流程。
- 本次上传不包含运行日志、真实连接配置、数据库备份、依赖目录、构建产物或本地预览截图。

正式版本标签应在合并并完成运行环境验收后创建。当前前端版本字段保持 0.1.0，不把分支快照冒充正式发布版本。

- 在本公开副本上离线安装前端依赖，三个前端回归脚本及 TypeScript/Vite 生产构建通过；终端绑定脚本覆盖普通和增强模式下的 16 个请求场景。
- 后端 Maven 多模块打包通过；140 项定向测试全部通过，无失败、无跳过。其中 4 项为本地 WSL shell 集成测试，包含旧目录作业读取与不重放检查。
