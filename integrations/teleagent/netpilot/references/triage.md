# 网络报障分诊

| 观察 | 可以告诉用户 | 需要进一步确认 |
| --- | --- | --- |
| 系统没解析出地址 | 本次采集环境未得到目标地址 | 地址是否正确、系统解析设置、网络是否正常 |
| 链路本地 IPv4 且两个地址族都无默认路由 | 地址分配或默认路由疑似有问题 | 网卡连接、DHCP、是否有其他专用路由 |
| 地址已解析，TCP 连接失败 | 本次没有建立目标端口的连接 | 服务监听、路径、访问策略 |
| TCP 已连，TLS 证书校验失败 | 客户端没有通过证书校验 | 域名、证书、时间、代理 |
| HTTP 3xx 或 4xx | 服务有响应，根路径要求跳转或返回客户端错误状态 | 浏览器实际访问路径、登录、权限 |
| HTTP 5xx | 目标或中间的 HTTP 服务报告异常 | 由站点管理员查服务或上游 |
| 有代理配置迹象、直连失败 | 需要对照原应用实际经过的网络路径 | 系统代理、PAC、浏览器或应用自身设置 |
| HTTP 2xx | 当前采集位置直连根路径获得成功响应 | 用户是否访问同一目标和路径，是否遇到门户页面或本机特有问题 |

对于超时、权限不足、命令缺失或采集来源不明的情况，按原状态记录，并指出需要补哪条证据。

报障摘要保留首次出现时间、实际站点、用户看到的提示、采集位置、证据 ID、当前影响范围、复测结果和管理员待查事项。设备、密码、认证参数和原始代理地址不放入摘要。
